Qué lo hace distinto

  • stet

    Un editor, todos los frameworks

    Componentes para Vue/Nuxt, React y Angular, y un elemento <awesome-editor> para cualquier otra página. Todos comparten la misma interfaz.

  • tr

    Modelo JSON, no HTMLModelo HTML, no JSON

    El documento es una estructura propia y validada. El HTML es una salida, no la fuente de verdad, así que el contenido se mantiene limpio.

  • ins

    Plugins de verdadPlugins de verdad

    Tablas, menciones, emojis, búsqueda y reemplazo, menús contextuales… Cada función es un plugin que puedes quitar o escribir tú.

  • ¶

    Abre, imprime y exporta

    Importa Markdown, HTML y Word; exporta a Markdown, HTML, Word (.docx) y PDF, o imprime directamente.

  • sp

    Cinco idiomas5 idiomas

    Español, inglés, francés, alemán y portugués de serie en toda la interfaz.

  • bf

    Claro y oscuro

    Temas con variables CSS que siguen al sistema o a tu elección, y que puedes adaptar a tu marca.
